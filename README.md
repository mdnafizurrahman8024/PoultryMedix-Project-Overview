# 🐔 PoultryMedix - Smart Veterinary Telemedicine & Flock Management

Welcome to the official project overview repository for **PoultryMedix**, an innovative web application designed to bridge the gap between poultry farmers and veterinary professionals through AI-driven insights and structured clinical management.

> **Note:** The core source code for this project is maintained in a private repository to protect intellectual property and secure user data structures. This public repository serves as a comprehensive overview of the project's architecture, features, and my technical contributions for academic and scholarship evaluations.

## 🌟 Project Overview

PoultryMedix is a comprehensive, scalable telemedicine platform tailored specifically for the poultry industry. It empowers farmers with proactive health management tools and provides veterinarians with a streamlined system for remote consultations, diagnostics, and digital prescription management.

## 👨‍💻 My Role: Project Lead & Full-Stack Developer

As the primary architect and developer of PoultryMedix, I led the project from conceptualization to deployment. My key responsibilities included:
*   **System Architecture:** Designing a robust, scalable architecture using modern web technologies (React, Tailwind CSS, Vite).
*   **AI Integration:** Implementing and fine-tuning the Gemini API for the Multimodal AI Chat and Smart Diagnosis Hub, ensuring accurate and context-aware veterinary triage.
*   **Full-Stack Development:** Developing the frontend user interface and integrating the backend database (Supabase) for seamless clinical data management.
*   **Localization (i18n):** Architecting a comprehensive multilingual system supporting English, Bengali, Hindi, and Urdu to ensure accessibility for diverse rural farming communities.

## ✨ Key Features & Functionality

1.  **🧠 Smart Diagnosis Hub:**
    *   AI-assisted triage summary based on farmer inputs and symptom descriptions.
    *   Integrated **Drug & Withdrawal Info** and a dynamic **Dose Calculator** for safe, precise medication practices.
2.  **💬 Multimodal AI Chat (Integrated with Gemini):**
    *   Supports text, voice (Live Record), and image/file uploads for accurate visual symptom analysis.
    *   Includes mandatory veterinary consulting alerts for user safety and ethical clinical compliance.
3.  **🌍 Unified Multilingual Support:**
    *   Seamless switching between English (EN), Bengali (বাংলা), Hindi (हिंदी), and Urdu (اردو) across the entire application interface.
4.  **📋 Comprehensive Clinical Log Dashboard:**
    *   **Smart Diagnosis & AI Chat History:** Secure local storage and retrieval of past AI interactions.
    *   **Digital Prescriptions:** Functionality for farmers to view, print, download (PDF), and share veterinary prescriptions.
    *   **Consultations & Payments:** Detailed records of vet appointments and integrated mock payment tracking (e.g., bKash, Cards).
5.  **🔔 Real-Time Govt Notices & Daily Tips:**
    *   A dynamic feed with a smart fallback search mechanism that queries external public web sources when local database information is unavailable.
6.  **🤝 Dedicated Contribute Module:**
    *   Structured forms for farmers to track essential flock metrics, farm details, and real-time bird health data.
